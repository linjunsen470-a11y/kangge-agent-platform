---

需要检查本仓库或审阅分支时，直接从仓库根目录运行（Python 3.11+，无需安装第三方依赖）：

```sh
python3 -I tools/check_repository.py
```

命令退出码为 0 表示静态规则检查通过，标准输出会打印已追踪文件、技能入口、仅依赖模块和配置计数。如有失败项，按标准错误中报告的文件路径与原因类别在本地复核修复。检查期间无须导入业务技能、安装依赖或访问外部服务。
