## 公开内容

- **技能依赖**。一份 Python 依赖表与上轮已核对原件的副本逐字节一致。另一份仅保留原有五行必需依赖声明及其次序，省略原说明文字。两份文件都改用通用目录名。
- **Workspace**。保留了项目已整理的工作约定和通用制作偏好。npm 包名、版本与完整性摘要来自原有清单。锁文件移除直接下载地址和上游弃用说明；全部 327 个锁定项的名称、版本和 SHA-512 均与公共注册表逐项相符。第三方包代码由使用者按需安装。
- **项目工程文件**。静态检查器与 Actions 来自本次仓库整理。仓库检查技能是这项工具的使用入口，单独编写且不计入原包的 6 项。本次公开版包含的原业务技能入口为 0。

## 隔离依据

前次审查已隔离 1,583 项，涉及凭据或标识风险、地址和样例数据、不可核验文件名或二进制、历史材料及明确的复制限制。此次公开复核再隔离 288 项，其中 287 项来自技能，1 项是引用未公开本地模块的诊断脚本。该数字也包含依附于这些实现的注册标记和资源。两轮决定互不重复。

在候选中查到许可证名称的模块，仍需明确该许可覆盖的发布者与版本。有的只有许可名称；另一个模块的许可证文件与公开上游一致，但候选中的实质性入口、脚本和文档未能确认为上游公开版本，可匹配的零散代码不足以组成独立功能。未经确认的改编、非公开操作说明、供应商接口、图片与模板留待权利人复核。

## 验证范围

公开分支从只含 README 的引导提交开始构建。检查覆盖候选文件、文件名、历史树、提交元数据和所有文件对象。首次交付在隔离目录从空缓存安装 npm 依赖，停用生命周期脚本，当前平台安装 305 个包。两份 Python 依赖表的 7 项直接约束通过仅使用二进制分发包的解析检查。Python 检查使用解析与编译，YAML 使用安全加载。实际远端结果以 PR 的 Checks 页面为准。

业务流程、外部服务、音视频处理与上游技能均未运行。原业务技能若要补充进仓库，应先定位对应来源序号，确认当前版本的公开授权与所需署名，并重新检查隐私与依赖。
