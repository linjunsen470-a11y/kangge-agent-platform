# 房产业务应用场景说明

这份文档结合本仓库当前已公开的工具底座与工作约定，说明 **Kangge Agent Platform** 在房产业务中的核心应用场景、每个场景能做什么，以及对应依赖哪些现成能力。

> **现状说明**：仓库目前提供的是**公开版工程底座与依赖环境**（文档/图表/图像/网页自动化工具包、Python 依赖清单、Agent 工作约定与隐私合规检查），具体私域业务脚本、客户数据与外部平台凭据未包含在公开分支中。下方场景说明的是：**基于本仓库底座（以及后续按需接入的业务技能），能够直接落地哪些房产工作流**。

---

## 二、分场景详细介绍

### 场景 1：楼盘测评报告、置业方案与推介 PPT 自动化

**业务痛点**：置业顾问、渠道团队或房产内容团队经常需要为不同客户/楼盘反复做对比方案、区域分析和推介 PPT，手工排版耗时且风格不统一。

**能干什么**：
- **Word / Markdown 深度报告**：用 `docx` 或 `marked` 结合结构化楼盘数据（区位、学区、地铁、户型、优缺点与价格区间），批量产出统一格式的《楼盘测评报告》《板块置业白皮书》或《项目复盘纪要》。
- **楼盘推介与选房对比 PPT**：用 `pptxgenjs` 自动生成带表格、亮点页和图表页的演示文稿，并通过 `@aiden0z/pptx-renderer` 辅助渲染检查版面效果。
- **可打印/可转发的 PDF 方案书**：结合 `skills/document-rendering`（`playwright` + `pypdf`），将 HTML/页面模板精准渲染成固定分页的 PDF 客户方案书，用于微信发送或线下带看打印。

---

### 场景 2：房源台账清洗、成交统计与市场图表生成

**业务痛点**：挂牌清单、成交明细、竞品报价单通常分散在多份 Excel/CSV 表格中，字段不统一、人工汇总和画图效率低。

**能干什么**：
- **房源与价格表批量整理**：通过 `exceljs`、`csv-parse`、`@json2csv/plainjs` 对多楼盘房源表、一房一价表、竞品成交台账做字段清洗、去重、单价/总价/得房率计算，并重新导出带样式的 Excel 汇总表。
- **楼市可视化图表输出**：使用 `echarts` 或 `d3` 生成：
  - 板块/小区月度均价与成交套数走势图；
  - 竞品楼盘面积段与总价带分布图；
  - 首付、月供、租金回报率或置业成本结构图。
- **统计与数值分析支撑**：借助 `skills/document-rendering` 中的 `numpy`、`scipy`，可进一步做价格分位数、波动趋势和异常挂牌价过滤。

---

### 场景 3：房源图片批处理与营销海报/长图渲染

**业务痛点**：实拍图、户型图、沙盘图尺寸不一、体积过大，或需要把房源参数快速排成适合公众号/小红书/朋友圈传播的长图和卡片。

**能干什么**：
- **图片批量规范化**：利用 `sharp`（Node）或 `Pillow`（Python）批量完成尺寸裁切、比例统一、压缩瘦身与格式转换，方便统一入库或嵌入 PPT/网页。
- **HTML 房源卡片/海报转高清图与 PDF**：通过 `playwright-core` 或 Python `playwright` 渲染 HTML/CSS 房源信息卡、户型对比长图、楼盘一页纸（One-Pager），输出高分辨率截图或 PDF，再由 `pypdf` 合并成整套楼盘资料册。

---

### 场景 4：公开楼市信息归档与房源接口数据校验

**业务痛点**：各地房产政策、土拍/预售公示、挂牌公开页面更新频繁；同时自建或对接的房源数据接口若出现字段缺失、类型漂移，容易导致下游报表或内容生成出错。

**能干什么**：
- **公开网页结构化解析**：利用 `axios` + `cheerio` + `dayjs`，按日期拉取和解析公开的政策文件、市场公示与楼盘基础信息（遵守目标站点合规要求），整理成统一时间戳的结构化文本或表格。
- **接口与数据结构自动校验**：基于 [skills/http-validation/requirements.txt](../skills/http-validation/requirements.txt)（`requests` + `jsonschema`），对房源详情、价格变动、小区字典等 API 响应进行自动化 Schema 校验，提前发现空字段、价格类型异常或接口变更。

---

### 场景 5：房产讲解/探盘短视频制作工作流支撑

**业务痛点**：房产自媒体或项目宣传需要高频产出楼盘讲解、板块分析、户型点评类短视频，容易出现配音风格漂移、语速生硬、画面重复剪辑以及素材目录混乱的问题。

**能干什么**：
- **统一成片与配音偏好**：[workspace/memory/MEMORY.md](../workspace/memory/MEMORY.md) 已沉淀通用制作约束——讲解视频配音保持一致（默认女声）、语速和停顿以自然听感为准、同一视频尽量避免重复镜头，供 AI Agent 在编写脚本、生成分镜或调用剪辑技能时遵循。
- **规范化素材与交付管理**：[workspace/AGENTS.md](../workspace/AGENTS.md) 明确了临时分析、中间文件和最终交付分目录保存、原始归档只读保护等规则，便于后续把字幕生成、配音合成、视频剪辑等业务技能安全接入同一套工作区。

---

### 场景 6：房产敏感信息与对外协作合规防护

**业务痛点**：房产业务天然包含大量敏感数据（客户电话、身份证号、业主联系信息、带签名的私密素材链接、合同/房源包压缩文件、外部服务 API 密钥），一旦在协作仓库中误提交，风险极高。

**能干什么**：
- **提交前与 PR 自动拦截**：[tools/check_repository.py](../tools/check_repository.py) 结合 GitGuardian CI，会在本地和 GitHub PR 上自动拦截常见密钥、带密码连接串、签名 URL、手机号/身份证号样式标识、个人邮箱、本机用户路径以及 `.zip`/`.db`/`.env` 等高风险文件。
- **安全沉淀通用资产**：帮助团队把“可复用的房产工具模板、通用提示词和工程脚本”留在公开仓库持续迭代，同时把客户隐私、私域素材和未确认授权的专有技能严格隔离在仓库之外。
