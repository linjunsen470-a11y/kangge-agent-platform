# 房产业务应用场景

制作报告、图表、图文资料或采集公告时，需要自行准备业务脚本和已获授权的数据。[按模块安装依赖](usage-guide.md)

| 工作 | 可复用的工具或约定 | 还需准备 |
| --- | --- | --- |
| 生成楼盘对比报告或推介 PPT | `docx`、`pptxgenjs` | 经授权的楼盘数据、排版模板和生成脚本 |
| 汇总成交台账并绘制均价走势图 | `exceljs`、`csv-parse`、`echarts` | 统一字段、去重规则和统计口径 |
| 批量处理房源图片，导出长图或 PDF | `sharp`、`Pillow`、Playwright、`pypdf` | 可使用的图片、卡片模板和渲染脚本 |
| 归档公开楼市公告，校验接口返回字段 | `axios`、`cheerio`、`requests`、`jsonschema` | 获准访问的数据源、字段规范和采集脚本 |
| 协作制作探盘短视频 | [配音与镜头偏好](../workspace/memory/MEMORY.md)、[交付约定](../workspace/AGENTS.md) | 单独准备获授权的素材和剪辑工具 |
| 公开模板前检查敏感信息 | [仓库检查器](../README.md#运行静态检查) | 提交前手动运行并核对结果。创建或更新 PR 后由 CI 自动报告 |
